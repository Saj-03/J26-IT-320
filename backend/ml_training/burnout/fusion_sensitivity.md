# Fusion robustness: random perturbation of weights and thresholds (scripted scenarios)

1000 random settings: weights and text gain +-20%, thresholds +-0.05. Default setting for comparison: 7/7.

- Fused matches all 7 expected outcomes in 89% of settings; average 6.9/7 (worst 6/7).
- Fused does at least as well as the best single-signal variant in 100% of settings.

| Scenario | Still as expected |
|---|---|
| S1 Steady week | 100% |
| S2 Exam crunch, all signals | 100% |
| S3 Quiet struggle (hidden from the Scheduler) | 89% |
| S4 Busy but coping | 100% |
| S5 Smiling but overloaded | 100% |
| S6 New student, low mood only | 100% |
| S7 Bounced back | 100% |

Reading: if the percentages are high, the result does not hinge on the exact hand-set numbers.
The weights remain initial heuristics, to be reviewed against pilot data.
